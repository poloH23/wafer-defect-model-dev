# data/raw

The MixedWM38 dataset is not part of this repository. Download it from its authors' repository,
[Junliangwangdhu/WaferMap](https://github.com/Junliangwangdhu/WaferMap), unzip it, and place
`Wafer_Map_Datasets.npz` in this folder: `data/raw/Wafer_Map_Datasets.npz`. Every run checks the file's
hash against the committed splits in `data/splits/`. See [Setup › Data](../../README.md#data) for the
source and its terms.

MixedWM38 資料集不包含在本 repo 中。請從作者的 repo 下載，解壓縮後把 `Wafer_Map_Datasets.npz` 放在這個資料夾，
也就是 `data/raw/Wafer_Map_Datasets.npz`。每次執行都會比對資料檔與 `data/splits/` 中固定切分的雜湊值。資料來源與
使用條款見 [README](../../README.zh-TW.md#開發環境與指令)。
