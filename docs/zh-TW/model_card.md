# Model card：晶圓缺陷分類模型

> 語言 : *[English](../../reports/final/model_card.md)*

## 模型

- **架構**：ShuffleNetV2 1.0x (`shufflenet_v2_x1_0`)，以 MixedWM38 從頭訓練，使用旋轉與翻轉的資料擴增。
- **交付的模型**：依照 [模型選擇規則](model_selection.md)，在驗證集上被選為三個部署目標 (雲端 GPU、CPU 伺服器、
  邊緣)模型的設定中，seed 0 的那一個。
- **格式**：單一的 ONNX 檔；輸入的編碼與 sigmoid 都在計算圖中，閾值與類別名稱寫在檔案的 metadata 裡。
  只需要 NumPy 與 ONNX Runtime 的參考推論實作：`src/inference/classifier.py`。

## 預期用途

將 52×52 的晶圓圖分類為 8 種缺陷，每張晶圓圖可能同時有任意組合的缺陷 (多標籤分類)。模型以部分為合成資料的
公開資料集訓練與評估，而不是產線的實際資料：它可以輔助晶圓圖的分析，但在依賴它的判斷之前，應該先在目標產線
上驗證。

## 輸入與輸出

- **輸入** `wafer_map`：uint8，形狀 (N, 52, 52)；每個晶粒一個類別代碼，0 為晶圓外、1 為良品、2 為不良。
  3 以上的數值依照訓練時的方式處理 (以鄰近像素的眾數補值)。
- **輸出** `probabilities`：float32，形狀 (N, 8)，每個類別一個機率，順序如下表。
- **判斷**：當某類別的機率達到它的閾值時，判定該缺陷存在；閾值在驗證集上調整。

| 類別 | 閾值 |
|---|---|
| Center | 0.50 |
| Donut | 0.50 |
| Edge_Loc | 0.80 |
| Edge_Ring | 0.05 |
| Loc | 0.40 |
| Near_Full | 0.50 |
| Scratch | 0.55 |
| Random | 0.55 |

## 效率

1.26M 個參數，每張晶圓圖 250 MFLOPs，ONNX 檔 5.3 MB。單張延遲的中位數 (`reports/experiments/benchmark.md`)：

- GPU (PyTorch FP32)：2.31 ms；批次處理時每秒 7,336 張
- CPU 伺服器 (ONNX Runtime，多執行緒)：0.82 ms
- 邊緣代理 (ONNX Runtime，1 個桌上型電腦執行緒；用於比較模型之間的快慢，不代表裝置上的延遲)：1.43 ms

## 匯出驗證

在驗證集的 3,700 張晶圓圖上，將原始晶圓圖經由 ONNX 檔與參考推論實作得到的結果，與 PyTorch checkpoint 在
訓練流程輸入上的結果比對：

- 機率的最大差異：1.2e-06
- 判斷結果不同的晶圓圖：0
- 批次推論與逐張推論的最大差異：0.0e+00

## 限制

- 訓練資料部分為合成資料，類別分佈也經過人為平衡：在產線上的精確率會有所不同。
- Edge_Loc 與 Edge_Ring 的標籤有模糊之處：錯誤集中在邊緣幾乎整圈都失效的晶圓上。
- 稀有類別 (Near_Full、Random)的測試張數很少，因此它們各自的數字不夠精確。
- 完整的限制清單，包括模型選擇過程的限制，請見 README 的 Limitations 一節。
